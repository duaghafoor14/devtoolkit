Frequently Asked Questions

A few things you should know before using the tools.

Do I need to create an account?
No. Dev Tool Kit is designed to work without registration or a user account.
Are my files uploaded to a server?
No. The tools are designed to process supported files and text directly inside your browser. Your files are not intentionally uploaded to a Dev Tool Kit server.
Can I use the tools on my phone?
Yes. The website is responsive and the tools are designed to work on modern desktop and mobile browsers.
Is the JWT Decoder verifying my token?
No. The JWT Decoder only decodes the token so you can inspect its contents. Decoding a JWT does not verify its signature or prove that the token is authentic.
Are the tools completely free?
The tools provided on Dev Tool Kit are intended to be free to use. Availability and supported features may change as the website develops.
