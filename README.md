# 🛠️ DevToolkit

A lightweight collection of useful web-based tools designed to make everyday developer tasks faster and easier.

DevToolkit brings several handy utilities together in one simple interface, with no complicated setup or unnecessary dependencies.

## ✨ Features

DevToolkit currently includes:

* 🔄 **JSON / YAML / CSV Converter** — Convert data between JSON, YAML, and CSV formats.
* 🔐 **JWT Decoder** — Decode and inspect JSON Web Tokens directly in the browser.
* 🧪 **Regex Tester** — Test regular expressions against text and check matches quickly.
* 📄 **PDF Merge & Split** — Merge multiple PDF files or split PDF pages.
* 🖼️ **Image to PDF** — Convert images into a PDF file.
* 📦 **ZIP Opener** — Open and extract files from ZIP archives.
* 📚 **About Page** — Information about DevToolkit and the project.
* 📩 **Contact Page** — Contact section for user feedback and inquiries.
* 🔒 **Privacy Policy & Terms** — Dedicated legal and informational pages.

## 🧰 Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**
* **PDF-LIB**
* **PDF.js**
* **JSZip**
* **Responsive Web Design**

The project is built primarily with vanilla HTML, CSS, and JavaScript, keeping it lightweight and easy to use.

## 🚀 Getting Started

DevToolkit is a frontend project, so there is no database or backend server required.

### Run locally

1. Clone the repository:

```bash
git clone https://github.com/duaghafoor14/devtoolkit.git
```

2. Open the project folder:

```bash
cd devtoolkit
```

3. Open `index.html` in your browser.

For the best experience during development, you can also use a local development server such as the **Live Server** extension in VS Code.
