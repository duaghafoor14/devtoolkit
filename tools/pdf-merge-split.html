FAQ

PDF Merge & Split FAQs

Can I merge more than two PDFs?

Yes. You can select multiple PDF files and arrange them in the order you want before merging them.

Can I choose specific pages to extract?

Yes. Enter page numbers or ranges such as 1, 3-5, 8 to create a new PDF containing only those pages.

Are my PDF files uploaded anywhere?

No. The PDF operations are performed directly inside your browser. Your selected files are not sent to a server by this tool.

Can I reorder PDFs before merging?

Yes. Use the up and down controls beside each selected PDF to change its position before merging.

Is there a file size limit?

There is no fixed server upload limit because processing happens locally. However, very large PDFs may require more browser memory.
