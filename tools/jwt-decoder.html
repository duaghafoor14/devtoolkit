                    Important security note

                    

                        Decoding a JWT does not prove that the token is
                        authentic or trustworthy. Anyone can decode the
                        header and payload of a JWT. Signature verification
                        is required to confirm that the token was actually
                        issued and signed by a trusted source.

What is a JWT?


                    

                        JSON Web Token (JWT) is a compact format commonly
                        used for securely transmitting information between
                        parties. JWTs are often used for authentication
                        and authorization in web applications and APIs.
                    


                    

                        A JWT normally contains three Base64URL-encoded
                        sections separated by dots:
                    


                    

                        Header
                        .
                        Payload
                        .
                        Signature
                    


                    

                        The header describes the token, the payload contains
                        claims, and the signature is used by a server to
                        verify that the token has not been modified.
                    


                


            


        



        
        


            


                


                    

                        FAQ
                    


                    
JWT Decoder FAQs



                    


                        

                            
                                Is decoding a JWT the same as verifying it?
                            

                            

                                No. Decoding only converts the encoded header
                                and payload into readable data. Verification
                                requires checking the token's signature using
                                the appropriate secret or public key.
                            

                        



                        

                            
                                Is my JWT uploaded to a server?
                            

                            

                                No. This decoder performs the decoding
                                directly in your browser and does not need
                                to send your token to a server.
                            

                        



                        

                            
                                Can I decode an expired JWT?
                            

                            

                                Yes. An expired token can still be decoded.
                                The expiration time is displayed so you can
                                see whether the token has passed its
                                expiration timestamp.
                            

                        



                        

                            
                                What are JWT claims?
                            

                            

                                Claims are pieces of information stored in
                                the JWT payload. Common examples include
                                issuer, subject, audience, issued-at time
                                and expiration time.
