What is a Regular Expression?

A regular expression, commonly called regex, is a pattern used to search, match or manipulate text. Regex is widely used for tasks such as finding email addresses, validating input, searching files and extracting information.

For example, this pattern can be used to find simple email addresses: 

\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}\b

Regex patterns are made from characters and special symbols that describe what text should be matched.

Examples

Common Regex Patterns

Email [\w.-]+@[\w.-]+\.\w+
Numbers \d+
Letters only [A-Za-z]+
Whitespace \s+
Phone number \+?\d[\d\s-]{7,}
URL https?://[^\s]+
FAQ

Regex Tester FAQs

What is regex used for?

Regex is commonly used to search, validate, extract and replace text based on a defined pattern.

What does the g flag mean?

The global flag tells the regular expression to find all matching occurrences instead of stopping after the first match.

What does the i flag mean?

The i flag makes the pattern case-insensitive. For example, an "a" can match both "a" and "A".

Is my test text uploaded?

No. This tool runs the regex directly in your browser, so your test text does not need to be sent to a server.
